## What's in the document

- **Part A — LLM literature-review challenge exercise**
  1. The challenge-task prompt issued to the LLM.
  2. The LLM's unedited v1 draft (600–800 word literature review, 10 references).
  3. A reference-verification table checking all 10 citations against primary
     sources (publisher pages, conference listings, arXiv records) — 4/10
     fully correct, 6/10 contained a venue/year/author metadata error, 0/10
     fabricated.
  4. The revised v2 document, edited with Microsoft Word **Track Changes**
     under the editor name "Qaium Hossain (Editor)" — every citation fix and
     two prose edits are preserved as visible insertions/deletions.
- **Part B — Writing skill derived from the edit**
  5. The `verified-literature-review` skill (also included standalone at
     [`skills/verified-literature-review/SKILL.md`](./skills/verified-literature-review/SKILL.md)).
  6. Discussion of why the skill works and its limitations.
- **Part C** — complete-sentence answers to the three lecture questions.
- **Part D** — the 20-question key-at-end quiz, reproduced with answers.
